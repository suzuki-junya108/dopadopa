# デザイン仕様

試作: `design/prototype.dc.html`。迷ったら試作に合わせる。

試作から変えた点（2026-10-07、ステップを操作単位に変えたことによる。理由は `docs/data-mapping.md`）:

- カードの大きな数字は % ではなく「いまの指示で完了したステップ数」。残り時間の代わりに「経過 1:05」を出す
- ステップのバーは区切りを持たない 1 本。作業中は状態色の縞模様が流れ、完了は黄緑、あなた待ちはオレンジ
- 区切りは 100 ステップごと、連続の告知は 50 / 100 / 150、カードの炎のバッジは 10 ステップ以上
- 状態に「コマンド実行中」（水色）と「待機中」（薄紫 `#9C8AC8`）を足した
- 画面全体のフラッシュは 1 秒に 1 回まで（複数のセッションが同時に終わったときの点滅を抑える）

## 方向性

ゲームセンターのように派手で、見ていて楽しい。ただし、言葉と数字は誰が見ても意味が分かること。

## 色（背景は濃い紫）

| 用途 | 色 | 上に載せる文字色 |
|---|---|---|
| 背景 | `#120A24` | `#FFFFFF` |
| カード | `#1E1238` | `#FFFFFF`、補足 `#C9B8F0` / `#E2D8FA` |
| 考え中 | `#C08BFF` | `#1A0838` |
| 編集中 | `#2EE6FF` | `#04161A` |
| テスト中 | `#FFE53B` | `#2A1E00` |
| あなた待ち | `#FF8A1F` | `#2A1200` |
| 失敗→自動修正中 | `#FF3D8B` | `#2A0414` |
| 完了 | `#9DFF3A` | `#102400` |

- 枠は黒 3px、影は色付きで「ずらした影」（`box-shadow: 6px 6px 0 <色>`）。グラデーションは使わない（進捗バーの斜め縞模様だけ例外）
- 角丸 14〜22px

## 文字

- 見出し・大きな告知: Dela Gothic One
- 数字・英字: Bungee（日本語が混ざる所は `Bungee, 'Dela Gothic One'`）
- 本文: M PLUS Rounded 1c（500 / 800）
- コマンドやファイル名: 等幅

## 画面の構成（上から）

1. ヘッダー: ロゴ / 今日完了したステップ（次の区切りまでのバー）/ 止まらずに進んだステップ（減っていくバー付き）/ 今日の目標（「タスクを 10 件完了する」と縞模様バー。1件ごとに「+1 件」が飛ぶ）/ 音 ON・OFF / 揺れ ON・OFF
2. 状態の数（稼働中 / あなた待ち / 今日の完了タスク / テスト通過）、勢い（直近 1 分のステップ数と 5 秒ごとの棒）、最新の出来事が横に流れる帯
3. 許可待ちの帯（あるときだけ）: 「許可待ち」「◯◯ が `npm install` の実行許可を待っています」「待ち時間 ◯秒」、拒否 / 承認する
4. セッションのカード（横 1 列。文が読める幅 440px を保ち、入りきらない分は横に送る）
5. 下段に横並び: 選択中のセッションの流れ（説明文と操作を起きた順に直近 6 件）/ 今日完了したタスク（積み木と直近 4 件）/ 時間帯ごとのステップと今日のステップの内訳 / ほかの目標（1 行ずつ）とセッション別 今日の完了ステップ
6. 画面の縁: 勢い（直近 1 分のステップ数）が 1 以上で水色の枠がゆっくり脈打ち、8 以上で速く、20 以上で黄色になりさらに速くなる（最速でも 0.7 秒周期）

「最近の出来事」の一覧は、上の流れる帯と重なるのでやめた。

### スクロールなしで 1 画面に収める

全体を見渡すための画面なので、縦にはみ出す分はウィンドウの高さに合わせて全体を縮める（`#root` の `zoom`）。

- 倍率は 100% から 1% 刻みで下げ、実際に収まった最大の値を使う。縮めると横に並ぶ数が増えて高さが段階的に変わるので、計算では求めない
- 下限は 50%。そこまで縮めても収まらないときだけ縦スクロールを残す（読めない大きさにしない）
- 幅 900px 未満（スマホ幅）では縮めず、縦に並べてスクロールする
- カードの行数は固定する（指示 2 行・説明文 5 行・いまの操作 3 行）。中身で高さが変わると、全体の倍率が更新のたびに揺れるため
- 告知・紙吹雪などの演出の層（`#fx`）は縮める対象の外に置き、縮小しても大きさを保つ

### 1 セッションを大きく表示

1 画面に収めると字が小さくなる（ノート PC で 6〜7 割）ので、読みたいセッションだけを縮めずに映す。

- 下段の「大きく表示」で開き、「閉じる」か Esc で閉じる。閉じると元のボタンにフォーカスが戻る
- 画面いっぱいの 1 枚に、名前・herdr での場所と題名（省略なし）・状態の札・指示・説明文（省略なし）・いまの操作・大きなステップ数・内訳・経過 / 変更行 / テスト通過・流れ（いまの指示の分をすべて、省略なし）を出す
- 「herdr で開く」と、許可待ちのときの拒否 / 承認するもここから押せる
- 開いている間は後ろのボードを操作できないようにする（`inert`）。告知や紙吹雪は手前に出続ける
- ステップが完了するたびに 1 枚全体が光る
- 幅 900px 未満では 1 列に並べ、縦にスクロールする

並び順: あなた待ち → 作業中 → 完了 → 待機中。同じ状態どうしは、待たせている順・新しく指示を受けた順・最近まで動いていた順（`docs/data-mapping.md`）。左ほど、いま見るべきセッションになる。

### カードの横並び

狭いカードでは「いま何をしているか」が途中で切れて読めなかったので、幅を保って横に送る形にした（ユーザーの指摘、2026-10-08）。

- カードは幅 440px から。セッションが少なければ横いっぱいに広がる
- 入りきらないときは、端に縦長のボタン「ほか 3 件 ▶」「◀ ほか 1 件」が立ち、押すとカード 1 枚ぶん送る。横スクロールでも送れる
- 並びが入れ替わるときは、元の位置から滑って移る（どれがどこへ動いたかを追えるように）
- 幅 900px 未満では従来どおり縦に並べる

## セッションのカード

上から「何を頼まれて・Claude が何と言っていて・いま何をしているか」が読める順に並べる。

- プロジェクト名、ブランチ、状態の札（ゆらゆら揺れる）
- herdr での場所と題名（1 行。「api-server / 負荷試験 ｜ 再接続の安定化」）。herdr の画面と見比べて、どのセッションかを見分けるための行（ユーザーの指摘、2026-10-10）。場所はワークスペース名で、タブに名前があるかタブが複数あるときだけ「/ タブ名」を添える。場所がプロジェクト名と同じなら題名だけを出す。題名は herdr が出しているものをそのまま出し、指示が届いても消さない
- 「指示: …」（受けた指示の冒頭、2 行）
- Claude の説明文（太字、5 行、左に状態色の線）。まだ無いときは「まだ説明文はありません」「指示を待っています」
- いまの操作（▶ 付き、3 行）。生のコマンドではなく「テストを実行」「index.html を編集中」のような言葉で出す
- 大きなステップ数（いまの指示の分）と、時間の札（「経過 1:05」「あなたの承認待ち」「完了」「指示を待っています」）
- ステップの内訳の帯と札: 「調べる（紫）/ 書く（水色）/ 動かす（白）/ 確かめる（黄）」の件数に比例して帯を塗り、下に 4 つの件数を並べる（狭いカードでも重ならないよう、数字の下に言葉を置く）。いま動いている種類は札が光り、帯のその部分に縞模様が流れる。順番に進む段階ではないので、矢印や「次へ」は描かない。作業中はカードの上の縁を光の帯が走る
- 10ステップ以上続けて進むと炎のバッジ「◯ステップ連続で進行中」。25 以上で炎と札とカードの影が大きくなり、50 以上でさらに大きく、札が黄色になる
- 許可待ちのときは拒否 / 承認するボタン

## 演出

| きっかけ | 演出 |
|---|---|
| ステップ完了 | カードに「調べる +1」など種類つきのポップ、内訳の件数が弾む、カードが光って数字から火花が散る、数字が回って増える、ヘッダーに「+1」、短い音（連続するほど高くなり、24 連続で 1 オクターブ上） |
| タスク完了 | カードに紙吹雪と「完了！」スタンプ、画面全体に紙吹雪、画面中央に「タスク完了！」と「◯ ステップ ・ 3:42」、積み木が 1 個落ちてくる、画面が揺れる、黄緑のフラッシュ、和音 |
| いまの指示が 10 ステップごと | カードに大きく「20 ステップ到達！」、カードの中に紙吹雪、カードが弾む、短い 3 音 |
| 今日 25 ステップごと（100 の倍数を除く） | 画面中央に「今日 125 ステップ完了」と「次の区切り 200 ステップまで あと 75」（通常の大きさ）、少なめの紙吹雪、短い 3 音。揺れとフラッシュは出さない |
| 100ステップごと | 特大の「今日 300 ステップ完了！」（長め）、画面全体に多めの紙吹雪、広がる輪、大きく揺れる、黄色フラッシュ、ファンファーレ |
| 今日の目標達成 | 特大の「今日の目標を達成！」、多めの紙吹雪、広がる輪、大きく揺れる、ピンクのフラッシュ。目標を +5 件 |
| いまの指示で最初の編集 | カードに大きく「この指示で最初の編集」 |
| テスト通過（件数が読み取れたとき） | カードに大きく「テスト 24 件通過！」（失敗のあとは「修正後のテスト 24 件通過！」）、カードを緑の波が横切る、上がっていく音 |
| セッションの連続が 25 / 50 | カードに大きく「25 ステップ連続！」、ピンクの波 |
| 50 / 100 / 150 連続 | 「50 ステップ連続！」、広がる輪、ピンクのフラッシュ |
| 何も起きていない時間 | 背景を小さな四角がゆっくり昇る。勢いの棒は直近 1 分にステップがあれば脈打つ |
| 許可待ちになった | オレンジの帯、カードが脈打つ、2回鳴る音 |
| 承認 | 大きな「承認しました」ポップ、カードを緑の波が横切る、高い音 |
| テスト失敗 | 状態札がピンク、低い音 |
| 連続が途切れた | 下がっていく音、出来事に記録 |
| ほかの目標達成 | 右上に「達成」のお知らせ |

- 揺れは設定でオフにできる。`prefers-reduced-motion` のときは動きを全部止める
- 音は初期値オフ。ON にするボタンを押したときに AudioContext を作る

## 用語表（必ずこの言葉を使う）

| 使う言葉 | 使わない言葉 |
|---|---|
| ステップ、タスク | クエスト |
| 完了、タスク完了！、すべて完了 | CLEAR、ALL CLEAR |
| あなた待ち、許可待ち、あなたの承認待ち、実行許可を待っています | 出番 |
| 失敗→自動修正中、テスト失敗を検知、修正を反映して再テスト中 | ピンチ、持ち直した、リベンジ |
| 止まらずに進んだステップ、◯ステップ連続 | コンボ、FEVER、ON FIRE |
| 今日完了したステップ、次の区切り、◯ ステップ到達 | XP、レベル、LEVEL UP |
| 今日の目標、ほかの目標、達成 | ボス、ミッション、実績解除 |
| （該当なし：削除済み） | 宝箱、ガチャ、称号、図鑑、クリティカル、レア度 |
| 新しいタスクを開始 | NEW QUEST |
| 承認する、拒否 | 承認する！（感嘆符なし） |
| ほか ◯ 件 | もっと見る、次へ |
| 大きく表示、閉じる | フォーカスモード、ズーム、拡大鏡 |
| 待機中、指示を待っています | アイドル |
| コマンド実行中 | 実行フェーズ |
| 経過 | （% と残り時間は出さない） |
| 勢い、直近 1 分 | テンション、ゲージ、ブースト |
| 指示、説明文、いまの操作、流れ | ログ、スレッド |
| ステップの内訳、調べる、書く、動かす、確かめる | フェーズ、ステージ、段階、進捗率 |
| 今日完了したタスク、時間帯ごとのステップ | 戦利品、スコアボード |
| 実装方針を組み立て中 | 作戦 |

原則: 「何が起きたか」をそのまま書く。新しい演出を足すときも、新しい概念や造語は作らない。
