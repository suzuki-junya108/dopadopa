# デザイン仕様

試作: `design/prototype.dc.html`。迷ったら試作に合わせる。

## 方向性

ゲームセンターのように派手で、見ていて楽しい。ただし、言葉と数字は誰が見ても意味が分かること。

## 色（背景は濃い紫）

| 用途 | 色 | 上に載せる文字色 |
|---|---|---|
| 背景 | `#120A24` | `#FFFFFF` |
| カード | `#1E1238` | `#FFFFFF`、補足 `#C9B8F0` / `#E2D8FA` |
| 考え中 | `#C08BFF` | `#1A0838` |
| 編集中 | `#2EE6FF` | `#04161A` |
| テスト中 | `#FFE53B` | `#2A1E00` |
| あなた待ち | `#FF8A1F` | `#2A1200` |
| 失敗→自動修正中 | `#FF3D8B` | `#2A0414` |
| 完了 | `#9DFF3A` | `#102400` |

- 枠は黒 3px、影は色付きで「ずらした影」（`box-shadow: 6px 6px 0 <色>`）。グラデーションは使わない（進捗バーの斜め縞模様だけ例外）
- 角丸 14〜22px

## 文字

- 見出し・大きな告知: Dela Gothic One
- 数字・英字: Bungee（日本語が混ざる所は `Bungee, 'Dela Gothic One'`）
- 本文: M PLUS Rounded 1c（500 / 800）
- コマンドやファイル名: 等幅

## 画面の構成（上から）

1. ヘッダー: ロゴ / 今日完了したステップ（次の区切りまでのバー）/ 止まらずに進んだステップ（減っていくバー付き）/ 音 ON・OFF
2. 今日の目標: 「タスクを 10 件完了する」と大きな縞模様バー。1件ごとに「+1 件」が飛ぶ
3. 状態の数（稼働中 / あなた待ち / 今日の完了タスク / テスト通過）と、最新の出来事が横に流れる帯
4. 許可待ちの帯（あるときだけ）: 「許可待ち」「◯◯ が `npm install` の実行許可を待っています」「待ち時間 ◯秒」、拒否 / 承認する
5. 左: セッションのカード / 右: 選択中のセッション詳細、ほかの目標、セッション別 今日の完了ステップ、最近の出来事

並び順: あなた待ち → 作業中 → それ以外。

## セッションのカード

- プロジェクト名、ブランチ、状態の札（ゆらゆら揺れる）
- 大きな % と「今日 ◯ ステップ完了」
- ステップのバー（完了は黄緑、進行中は状態色の縞模様が流れる）
- 何をしているか（太字）と、直近の操作（等幅）
- 「2 / 6 ・ フォームに接続」と残り時間（「残り約 1:05」「あなたの承認待ち」「次のタスクまで ◯秒」）
- 3ステップ以上続けて進むと炎のバッジ「◯ステップ連続で進行中」
- 許可待ちのときは拒否 / 承認するボタン

## 演出

| きっかけ | 演出 |
|---|---|
| ステップ完了 | カードに「+1 ステップ完了」がポップ、数字が跳ねる、短い音 |
| タスク完了 | カードに紙吹雪と「完了！」スタンプ、画面中央に「タスク完了！」、画面が揺れる、黄緑のフラッシュ、和音 |
| 25ステップごと | 「今日 150 ステップ完了！」、大きく揺れる、黄色フラッシュ、ファンファーレ |
| 今日の目標達成 | 「今日の目標を達成！」、大きく揺れる、ピンクのフラッシュ。目標を +5 件 |
| 10 / 20 / 30 連続 | 「20 ステップ連続！」、ピンクのフラッシュ |
| 許可待ちになった | オレンジの帯、カードが脈打つ、2回鳴る音 |
| 承認 | 「承認しました」ポップ、高い音 |
| テスト失敗 | 状態札がピンク、低い音 |
| 連続が途切れた | 下がっていく音、出来事に記録 |
| ほかの目標達成 | 右上に「達成」のお知らせ |

- 揺れは設定でオフにできる。`prefers-reduced-motion` のときは動きを全部止める
- 音は初期値オフ。ON にするボタンを押したときに AudioContext を作る

## 用語表（必ずこの言葉を使う）

| 使う言葉 | 使わない言葉 |
|---|---|
| ステップ、タスク | クエスト |
| 完了、タスク完了！、すべて完了 | CLEAR、ALL CLEAR |
| あなた待ち、許可待ち、あなたの承認待ち、実行許可を待っています | 出番 |
| 失敗→自動修正中、テスト失敗を検知、修正を反映して再テスト中 | ピンチ、持ち直した、リベンジ |
| 止まらずに進んだステップ、◯ステップ連続 | コンボ、FEVER、ON FIRE |
| 今日完了したステップ、次の区切り | XP、レベル、LEVEL UP |
| 今日の目標、ほかの目標、達成 | ボス、ミッション、実績解除 |
| （該当なし：削除済み） | 宝箱、ガチャ、称号、図鑑、クリティカル、レア度 |
| 新しいタスクを開始 | NEW QUEST |
| 承認する、拒否 | 承認する！（感嘆符なし） |
| 実装方針を組み立て中 | 作戦 |

原則: 「何が起きたか」をそのまま書く。新しい演出を足すときも、新しい概念や造語は作らない。
