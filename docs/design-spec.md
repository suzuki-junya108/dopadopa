# デザイン仕様

試作: `design/prototype.dc.html`。迷ったら試作に合わせる。

試作から変えた点のうち、セッションの並べ方（2026-10-10）: カードの列をやめ、全セッションを区切りつきの行の一覧にした。カードは 1440 幅で 3〜4 枚しか見えず、全体を見渡すには横に送る必要があったため（ユーザーが別の定期報告の表形式を「見やすかった」と示したのを受けた変更）。以下の「カード」は「行」に読み替える。

試作から変えた点（2026-10-07、ステップを操作単位に変えたことによる。理由は `docs/data-mapping.md`）:

- カードの大きな数字は % ではなく「いまの指示で完了したステップ数」。残り時間の代わりに「経過 1:05」を出す
- ステップのバーは区切りを持たない 1 本。作業中は状態色の縞模様が流れ、完了は黄緑、あなた待ちはオレンジ
- 区切りは 100 ステップごと、連続の告知は 50 / 100 / 150、カードの炎のバッジは 10 ステップ以上
- 状態に「コマンド実行中」（水色）と「待機中」（薄紫 `#9C8AC8`）を足した
- 画面全体のフラッシュは 1 秒に 1 回まで（複数のセッションが同時に終わったときの点滅を抑える）

## 方向性

ゲームセンターのように派手で、見ていて楽しい。ただし、言葉と数字は誰が見ても意味が分かること。

## 色（背景は濃い紫）

| 用途 | 色 | 上に載せる文字色 |
|---|---|---|
| 背景 | `#120A24` | `#FFFFFF` |
| カード | `#1E1238` | `#FFFFFF`、補足 `#C9B8F0` / `#E2D8FA` |
| 考え中 | `#C08BFF` | `#1A0838` |
| 編集中 | `#2EE6FF` | `#04161A` |
| テスト中 | `#FFE53B` | `#2A1E00` |
| あなた待ち | `#FF8A1F` | `#2A1200` |
| 失敗→自動修正中 | `#FF3D8B` | `#2A0414` |
| 完了 | `#9DFF3A` | `#102400` |

- 枠は黒 3px、影は色付きで「ずらした影」（`box-shadow: 6px 6px 0 <色>`）。グラデーションは使わない（進捗バーの斜め縞模様だけ例外）
- 角丸 14〜22px

## 文字

- 見出し・大きな告知: Dela Gothic One
- 数字・英字: Bungee（日本語が混ざる所は `Bungee, 'Dela Gothic One'`）
- 本文: M PLUS Rounded 1c（500 / 800）
- コマンドやファイル名: 等幅

## 画面の構成（上から）

1. ヘッダー: ロゴ / 今日完了したステップ（次の区切りまでのバー）/ 止まらずに進んだステップ（減っていくバー付き）/ 今日の目標（「タスクを 10 件完了する」と縞模様バー。1件ごとに「+1 件」が飛ぶ）/ 音 ON・OFF / 揺れ ON・OFF
2. 状態の数（稼働中 / あなた待ち / 今日の完了タスク / テスト通過）、勢い（直近 1 分のステップ数と 5 秒ごとの棒）、最新の出来事が横に流れる帯
3. セッションの一覧（全セッションを 1 画面に。下の「セッションの一覧」を参照）。許可待ちの別枠の帯はやめ、行そのものをオレンジにして拒否 / 承認するを置く
4. 下段に横並び: 選択中のセッションの流れ（説明文と操作を起きた順に直近 6 件）/ 今日完了したタスク（積み木と直近 4 件）/ 時間帯ごとのステップと今日のステップの内訳 / ほかの目標（1 行ずつ）とセッション別 今日の完了ステップ
5. 画面の縁: 勢い（直近 1 分のステップ数）が 1 以上で水色の枠がゆっくり脈打ち、8 以上で速く、20 以上で黄色になりさらに速くなる（最速でも 0.7 秒周期）

「最近の出来事」の一覧は、上の流れる帯と重なるのでやめた。

### スクロールなしで 1 画面に収める

全体を見渡すための画面なので、縦にはみ出す分はウィンドウの高さに合わせて全体を縮める（`#root` の `zoom`）。

- 倍率は 100% から 1% 刻みで下げ、実際に収まった最大の値を使う。縮めると横に並ぶ数が増えて高さが段階的に変わるので、計算では求めない
- 下限は 50%。そこまで縮めても収まらないときだけ縦スクロールを残す（読めない大きさにしない）
- 幅 900px 未満（スマホ幅）では縮めず、縦に並べてスクロールする
- 行の中の行数は固定する（場所と題名 2 行・説明文 2 行・いまの操作 1 行）。中身で高さが変わると、全体の倍率が更新のたびに揺れるため
- 行は全件を縦に積むので、セッションが増えるほど縮む。実測（2026-10-10、模擬、1440x800）: 3 個で 0.79、7 個で 0.65、12 個で 0.57。カードの列は何個でも 0.72 だった。全件を見渡せることと字の大きさの引き換えで、前者を取った
- 告知・紙吹雪などの演出の層（`#fx`）は縮める対象の外に置き、縮小しても大きさを保つ

### 1 セッションを大きく表示

1 画面に収めると字が小さくなる（ノート PC で 6〜7 割）ので、読みたいセッションだけを縮めずに映す。

- 下段の「大きく表示」で開き、「閉じる」か Esc で閉じる。閉じると元のボタンにフォーカスが戻る
- 画面いっぱいの 1 枚に、名前・herdr での場所と題名（省略なし）・状態の札・指示・説明文（省略なし）・いまの操作・大きなステップ数・内訳・経過 / 変更行 / テスト通過・流れ（いまの指示の分をすべて、省略なし）を出す
- 「herdr で開く」と、許可待ちのときの拒否 / 承認するもここから押せる
- 開いている間は後ろのボードを操作できないようにする（`inert`）。告知や紙吹雪は手前に出続ける
- ステップが完了するたびに 1 枚全体が光る
- 幅 900px 未満では 1 列に並べ、縦にスクロールする

## セッションの一覧

全セッションを送らずに見渡せるよう、1 セッション 1 行で縦に積む。罫線だけの表にはせず、行はカードと同じ黒い枠・状態色のずらした影・揺れる状態の札を持つ。列の位置だけを全行でそろえる。

区切りは 3 つ。上ほど、いま見るべきセッションになる（並び順は `docs/data-mapping.md`）。

| 区切り | 入るもの | 形 |
|---|---|---|
| 冒頭の 1 文「あなたの対応が要るものは ◯ 件です」 | 許可待ち・あなた待ちと、完了してまだ見ていないセッション。0 件なら黄緑で「あなたの対応が要るものはありません」 | 行 |
| 動いているもの | 作業中のセッション | 行 |
| 指示を待っているもの | 見たあとの完了と、待機中 | 小さな札（横に並べて折り返す）。動きのないセッションに 1 行使わないため |

行の列（左から）:

- herdr での場所と題名（太字 2 行。無ければプロジェクト名）と、その下にプロジェクト名・ブランチ。ここを押すと下段に流れが出る
- 状態の札
- いつから: 許可待ちは「待ち 20秒」、作業中は「経過 1:05」、完了と待機中は「4分前」。ブリッジが見ていない時刻は出さない
- いまの状況: Claude の説明文の冒頭（2 行、左に状態色の線）と、その下に「▶ いまの操作」（無ければ「指示: …」）。許可待ちのときは「「npm run build」の実行許可を待っています」。冒頭を出す根拠は実測（2026-10-10、7 セッションの指示ごとの最後の応答 49 件）: 応答の中央値は 1,426 文字で 280 文字に収まるものは 0 件、結論はどれも冒頭の 1〜2 文にあった
- いまの指示のステップ数、ステップの内訳の細い帯、10 ステップ以上続くと炎のバッジ「◯連続」（25 以上で影が大きくなり、50 以上で影と札が黄色）
- 許可待ちのときだけ 拒否 / 承認する（こちらから答えられない待ちは「herdr で開く」）

小さな札には、場所と題名・プロジェクト名・状態・いつからだけを出す。説明文は、押して下段か「大きく表示」で読む。

- 作業中の行は、下の縁を光の帯が端から端まで走る
- 許可待ちの行は、行全体がオレンジになって脈打つ
- 区切りをまたいで移るときは、元の位置から滑って移る（終わったものが上に飛んでくるので、何が起きたかを位置で追える）
- Stop が届いてから herdr が「見た・見ていない」を知らせるまでの数秒は、行き先が決まらないので動かさない
- 幅 900px 未満では、行の中身を縦に並べる

## 演出

| きっかけ | 演出 |
|---|---|
| ステップ完了 | 行に「調べる +1」など種類つきのポップ、行が光って白い光が端から端へ走り、数字から火花が散る、数字が回って増える、ヘッダーに「+1」、短い音（連続するほど高くなり、24 連続で 1 オクターブ上） |
| タスク完了 | 行から紙吹雪と「完了！」スタンプ、行が「あなたの対応が要るもの」へ滑って上がる（見ているセッションなら「指示を待っているもの」へ）、画面全体に紙吹雪、画面中央に「タスク完了！」と「◯ ステップ ・ 3:42」、積み木が 1 個落ちてくる、画面が揺れる、黄緑のフラッシュ、和音 |
| いまの指示が 10 ステップごと | 「20 ステップ到達！」の文字が行の端から端まで横切る、行から紙吹雪、行が弾む、短い 3 音 |
| 今日 25 ステップごと（100 の倍数を除く） | 画面中央に「今日 125 ステップ完了」と「次の区切り 200 ステップまで あと 75」（通常の大きさ）、少なめの紙吹雪、短い 3 音。揺れとフラッシュは出さない |
| 100ステップごと | 特大の「今日 300 ステップ完了！」（長め）、画面全体に多めの紙吹雪、広がる輪、大きく揺れる、黄色フラッシュ、ファンファーレ |
| 今日の目標達成 | 特大の「今日の目標を達成！」、多めの紙吹雪、広がる輪、大きく揺れる、ピンクのフラッシュ。目標を +5 件 |
| いまの指示で最初の編集 | 行に大きく「この指示で最初の編集」 |
| テスト通過（件数が読み取れたとき） | 行に大きく「テスト 24 件通過！」（失敗のあとは「修正後のテスト 24 件通過！」）、行の端から端まで緑の波が横切る、上がっていく音 |
| セッションの連続が 25 / 50 | 行に大きく「25 ステップ連続！」、ピンクの波 |
| 50 / 100 / 150 連続 | 「50 ステップ連続！」、広がる輪、ピンクのフラッシュ |
| 何も起きていない時間 | 背景を小さな四角がゆっくり昇る。勢いの棒は直近 1 分にステップがあれば脈打つ |
| 許可待ちになった | 行がオレンジになって脈打ち、いちばん上へ滑って上がる、冒頭の 1 文の件数が弾む、2回鳴る音 |
| 承認 | 大きな「承認しました」ポップ、行を緑の波が横切る、高い音 |
| テスト失敗 | 状態札がピンク、低い音 |
| 連続が途切れた | 下がっていく音、出来事に記録 |
| ほかの目標達成 | 右上に「達成」のお知らせ |

- 揺れは設定でオフにできる。`prefers-reduced-motion` のときは動きを全部止める
- 音は初期値オフ。ON にするボタンを押したときに AudioContext を作る

## 用語表（必ずこの言葉を使う）

| 使う言葉 | 使わない言葉 |
|---|---|
| ステップ、タスク | クエスト |
| 完了、タスク完了！、すべて完了 | CLEAR、ALL CLEAR |
| あなた待ち、許可待ち、あなたの承認待ち、実行許可を待っています | 出番 |
| 失敗→自動修正中、テスト失敗を検知、修正を反映して再テスト中 | ピンチ、持ち直した、リベンジ |
| 止まらずに進んだステップ、◯ステップ連続 | コンボ、FEVER、ON FIRE |
| 今日完了したステップ、次の区切り、◯ ステップ到達 | XP、レベル、LEVEL UP |
| 今日の目標、ほかの目標、達成 | ボス、ミッション、実績解除 |
| （該当なし：削除済み） | 宝箱、ガチャ、称号、図鑑、クリティカル、レア度 |
| 新しいタスクを開始 | NEW QUEST |
| 承認する、拒否 | 承認する！（感嘆符なし） |
| あなたの対応が要るもの、動いているもの、指示を待っているもの | 要対応、アクティブ、アイドル、キュー |
| 待ち ◯秒、◯分前、経過 | 滞留、最終更新 |
| 大きく表示、閉じる | フォーカスモード、ズーム、拡大鏡 |
| 待機中、指示を待っています | アイドル |
| コマンド実行中 | 実行フェーズ |
| 経過 | （% と残り時間は出さない） |
| 勢い、直近 1 分 | テンション、ゲージ、ブースト |
| 指示、説明文、いまの操作、流れ | ログ、スレッド |
| ステップの内訳、調べる、書く、動かす、確かめる | フェーズ、ステージ、段階、進捗率 |
| 今日完了したタスク、時間帯ごとのステップ | 戦利品、スコアボード |
| 実装方針を組み立て中 | 作戦 |

原則: 「何が起きたか」をそのまま書く。新しい演出を足すときも、新しい概念や造語は作らない。
